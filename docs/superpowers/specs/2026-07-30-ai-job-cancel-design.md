# AI 작업 취소 설계

## 목표

관리자가 진행 중인 Wiki 변환 작업을 중단해, 현재 처리 문서는 완료시키고 아직 시작하지 않은 문서는 `CANCELLED`로 기록한다(FR-AI-007).

## 범위

- 공개 API `POST /api/v1/ai-jobs/{jobId}/cancel`을 추가한다.
- 관리자만 요청할 수 있고, 존재하지 않는 작업은 404, 이미 종료된 작업은 409으로 처리한다.
- ERD와 엔티티 컬럼을 바꾸지 않는다.

## 동작

취소 요청 서비스는 작업 상태를 즉시 `CANCELLED`로 바꾸고, 문서 ID 순서에서 아직 시작하지 않은 `UPLOADED` 문서를 즉시 `CANCELLED`로 전환한다. 현재 `PARSING` 또는 `PROCESSING` 문서는 강제 중단하지 않는다.

워커는 각 문서 시작 전에 DB에서 작업 상태를 다시 읽어 `CANCELLED`면 다음 문서를 시작하지 않고 종료한다. 문서 1건이 끝날 때마다 결과를 기존 `ai_job.document_results` JSON에 누적 저장한다. 따라서 취소 요청과 현재 문서 완료가 교차해도 완료·실패 결과는 유지되고, 작업 상태가 완료로 되돌아가지 않는다.

## 검증

- 관리자 취소가 202과 cancelled 상태를 반환한다.
- 진행 중 문서는 처리되고 대기 문서만 취소되며, 워커는 취소 뒤 다음 문서를 시작하지 않는다.
- 취소 문서는 워커가 FastAPI 호출 없이 건너뛴다.
- 비관리자, 없는 작업, 종료 작업의 403/404/409을 검증한다.
