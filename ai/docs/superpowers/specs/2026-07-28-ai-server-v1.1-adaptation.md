- 작성: 2026-07-28

## 1. 무엇이 확정됐나

**pull → push.** AI 서버는 Spring에 되묻지 않는다. Spring이 2단계로 부른다:

```
1단계  POST /internal/v1/wiki-context-selections
       parsedMarkdown + currentIndex (+ changeType, removed/new markdown)
       → wikiIds ≤ 5 + reason

2단계  POST /internal/v1/wiki-transformations
       + selectedWikis[] (wikiId·categoryId·title·summary·contentMarkdown·documentRefs·wikiRefs)
       + changeType: document_added | document_removed | document_replaced
       + removedParsedMarkdown (removed·replaced 시)
       → 기존 응답 형식 (summary·categoryChanges·wikiChanges·relationChanges·indexEntries)
```

- 재조정 별도 엔드포인트 없음 — changeType이 대체
- 단건 조회 없음 — 미선택 위키는 이번 변환에서 불변 (품질 리스크, 측정 대상)
- `evidence`·`failureStage` 수용, 미지 필드 무시 (전방 호환)
- 36k자 검증: 업로드가 아니라 **변환 접수 시** `parsedMarkdown` 기준. 초과 → 실패 + 사유
- 시간 상한: 최대 30분 (기존 `runtime/limits.py` 그대로), Spring read timeout 31분+
- `wiki-edits`는 변경 없음
- changeType이 변환 요청에도 실린다는 가정으로 짓는다 (회신에 명기, 뒤집히면 필드 이동만)

## 2. 데이터 흐름 (한 요청)

```
transform 도착: selectedWikis[] 포함
  1  길이 검사        len(parsedMarkdown) > 약 36k → 실패 (failureStage: context_load)
  2  라이브 층 채움    selectedWikis[] → 임시 SQLite (본문·관계·청크 FTS·참조 그래프)
                      + index.md는 currentIndex 로, 원본문서는 parsedMarkdown/removedParsedMarkdown 으로
  3  에이전트          기존 그대로 (guide → search → read → write → lint)
  4  응답 조립         기존 changes.py 그대로
```

HTTP 호출 0회. `SpringClient` · grant · 읽기 4개가 전부 사라진다.

## 3. 주소 체계

selectedWikis에는 wikiPath가 없고 목차 링크가 `pages/{wikiId}.md`(v1.1.0 예시)다.
**기존 페이지의 내부 주소를 `pages/{wikiId}.md`로 쓴다** (wikiId가 이미 있으니 유일함 보장).
새 페이지는 지금처럼 에이전트가 pageKey를 발급하고 `tempWikiId`로 응답 — Spring이
실제 ID 발급 후 파일명·링크를 정한다 (indexEntries 기반으로 목차도 Spring이 재구성).
`changes.py`의 wikiPath 응답 필드는 유지하되 값을 이 체계로 낸다 (미지 필드 무시라 무해).

## 5. 선택(selection)의 구현 방식

에이전트(MCP 툴 루프)가 아니라 **단발 LLM 호출**이다 — 입력이 목차+문서뿐이라 툴이 필요 없다.
프롬프트: 목차의 각 항목(제목·요약·링크의 wikiId)과 새 문서를 주고 "이 문서를 반영할 때
읽어야 할 위키를 관련도 순서로 최대 5개, wikiId로" 요구. 응답은 구조화(JSON).
changeType이 removed면 "이 문서를 근거로 쓴 위키"를 고르라는 지시로 바뀐다 —
목차 요약만으로는 각주 관계를 모르므로 **선택 정확도가 낮을 수 있음을 명기**하고 측정 대상에 올린다.
