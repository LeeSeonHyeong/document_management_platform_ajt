## 판정

**통과.** 점검 결과 언급이 사라졌고 첫 단어부터 반영 내용이다. 파일 이름·시스템 용어도 없다.

세 번의 측정이 남긴 것:

| | 첫 줄 | 판정 |
| --- | --- | --- |
| v1 (독자만 명시) | `error 0건, lint 통과 확인 완료.` | 실패 |
| v2 (`lint` 금지) | `오류 없이 통과했습니다.` | 실패 — 동의어 우회 |
| v3 (범주 금지 + 나쁜 예) | `연차 휴가 관련 인사 공지를 바탕으로…` | 통과 |

**교훈: 금지할 낱말을 열거하면 뜻이 같은 다른 낱말로 새어 나온다.** 무엇을 쓰지 말라고
할 때는 낱말이 아니라 **그 말이 하는 일**(내부 점검 결과 보고)을 금지하고, 실제로 새어 나온
문장을 나쁜 예로 붙여야 막힌다.

**남은 한계**

- 코퍼스 1건·1회 측정이다. 다른 문서에서도 같은지는 확인하지 않았다
- 편집(`edit_instruction`) 경로는 같은 원칙만 넣었고 실기동으로 재지 않았다
- `turns`·`costUsd` 가 0 이다 — Spring 을 거친 경로(`viaApi`)라 툴 집계가 수집되지 않는다
