# 리팩토링 전 리포트

⚠ **이 리포트들의 지표는 현재 실험과 대조할 수 없다.**

C안 리팩토링(2단 저장 · `pageKey` 주소 · 카테고리 DB화 · 작업 공간) 전 구조에서 나왔다.
저장 레이아웃·관계 그래프·lint 검사 항목이 모두 다르고, 워크스페이스는 이미 삭제됐다.

지우지 않고 남긴 이유는 하나다 — `sonnet5-2docs.json` 이 **`claude-sonnet-5` 로 돌린 유일한
기록**이다. 이후 측정은 전부 `claude-opus-4-6` 이라, 모델 간 차이를 다시 볼 일이 있으면
출발점이 된다. 단, 코드가 달라서 그 차이가 모델 탓인지 코드 탓인지 이 데이터로는 못 가린다.

| 파일 | 무엇 |
|---|---|
| `ingest-01.json` `ingest-02.json` | 첫 e2e 2건. 툴 카운트가 비어 있다 (CLI가 안 알려줘서, 이후 서버가 세게 고쳤다) |
| `sonnet5-2docs.json` | `claude-sonnet-5` 2건. 페이지간 링크 0 — 그 모델은 본문 링크를 안 썼다 |
| `opus46-2docs.json` | `claude-opus-4-6` 2건. 위와 비교해 링크 2건이 나왔다 |

sonnet-5 와 opus-4-6 을 나란히 본 결론은 `spikes/wiki-convert-loop/FINDINGS.md` §9 에 있다.
