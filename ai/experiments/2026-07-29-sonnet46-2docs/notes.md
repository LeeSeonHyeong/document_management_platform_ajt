## 판정

**하드 게이트는 전부 통과한다.** `lint` error 0, 조각 0, 각주 25건이 **전부** 원문을 그대로
인용하고 위치가 있다. 표와 mermaid 를 잃지 않았고 create/update 균형도 같다. 이전 spike 의
실패 모드(조각 13/26, 카테고리 붕괴)는 재현되지 않았다 — **guide 가 sonnet 에서도 떠받친다.**

**대신 덜 촘촘하다.** 각주가 31% 적고(36 → 25) 본문도 18% 짧다. 붙인 것의 정확도는 같다
(25건 전부 원문 인용). **품질이 아니라 밀도의 차이다.**

**원인은 `search` 로 보인다.** 툴 호출 총합은 24로 같은데 구성이 다르다 — opus 는
search 6·read 6, sonnet 은 search 4·read 8. 겹치는 페이지를 덜 찾으니 관계를 덜 만들고
근거도 덜 붙인다. 이것이 링크 0 과 각주 31% 감소를 함께 설명한다.

**페이지간 링크 0 이 유일한 회귀 후보다.** 같은 guide 의 opus 는 2개를 만들었다. 다만 페이지가 2개면
가능한 링크가 최대 1개라 n=1 이고, 이것만으로 판정할 수 없다. 이전 spike 의 대표 실패가
"페이지간 관계 0" 이었으므로 **12건에서 반드시 확인해야 하는 지표다** (opus 12건은 69).
