PostHog는 직급에 관계없이 전 구성원에게 연간 교육 훈련 예산을 제공한다[^1]. 별도 승인 없이 사용할 수 있지만, 매니저와 사전에 논의하면 더 나은 방향을 잡을 수 있다[^2].

## 예산 개요

| 항목 | 내용 |
|------|------|
| 연간 기본 한도 | $1,000 (역년 기준)[^3] |
| 초과 사용 | Brex에서 증액 요청 시 대부분 승인[^4] |
| 사용 범위 | 강좌, 훈련, 공인 자격, 컨퍼런스[^5] |

## 비기술직 프로그래밍 학습 권장

비기술직 구성원에게 기초 프로그래밍 과정 수강을 강력히 권장한다[^6]. Codecademy에서 Python, React 등 사내 기술 스택을 배울 수 있다[^7].

```mermaid
graph LR
    A["교육 예산 확인"] --> B["과정 선택"]
    B --> C["수강 완료"]
    C --> D["팀에 학습 내용 공유"]
```

학습 후 팀과 결과를 공유하는 것이 권장된다[^8].

## 컨퍼런스 참가

교육 예산은 컨퍼런스 발표·사용자 모임·코칭 활동에도 사용할 수 있다[^9]. 월 최대 반나절까지 이런 활동에 시간을 쓸 수 있으며, 이 역시 엄격한 상한은 아니다[^10].

> **참고:** 도서 구매는 별도 월간 예산이 있다. [도서 지원 정책](pages/b63430958f86.md) 참고.

> **참고:** PostHog의 커리어 성장 철학과 성장 지원 방식은 [커리어 성장](pages/b5f176c9b3e6.md) 참고.
