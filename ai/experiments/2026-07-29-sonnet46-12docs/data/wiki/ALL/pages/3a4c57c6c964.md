## GitHub 활용

PostHog는 비엔지니어링 업무 관리를 포함해 **모든 것에 GitHub를 사용한다**[^2].

### 주요 저장소

| 저장소 | 설명 |
|--------|------|
| [PostHog](https://github.com/PostHog/posthog) | 메인 앱 |
| [PostHog.com](https://github.com/PostHog/posthog.com) | 웹사이트 |
| Product Internal (비공개) | 보안·고객 관련 내부 이슈 |
| Company Internal (비공개) | 내부 프로세스, 채용 계획 |

### GitHub Projects

GitHub Projects로 이슈 상태를 시각적으로 관리한다. 이슈 생성 시 관련 Project에 배정하면 소규모 팀이 여러 저장소를 오가지 않고도 작업 현황을 추적할 수 있다[^3].

- 이슈에 **담당자**와 **레이블**을 지정해 필터링을 돕는다
- 각 소규모 팀마다 전담 Project가 있다
- 대부분의 팀은 **2주 스프린트**로 운영된다. 온보딩 과정에서 관련 계획 미팅에 초대된다[^3]
