PostHog는 모든 구성원에게 주식 옵션을 부여한다[^1]. 부여 규모는 역할·레벨·위치에 따라 결정되며, 평균 수준의 주식이지만 업계에서 가장 구성원 친화적인 조건으로 설계되었다[^2].

## 핵심 조건

| 항목 | 내용 |
|------|------|
| 베스팅 기간 | 4년 (1년 클리프) |
| 퇴사 후 행사 기간 | **10년** |
| 이중 트리거 가속 (Double Trigger) | 인수 후 강제 퇴사 시 전량 즉시 부여 |
| 베스팅 시작일 | 입사일 (수습·시보 기간 없음) |
| UK 구성원 | EMI 또는 CSOP 세금 혜택 제도 적용 가능 |

### 퇴사 후 행사 기간

PostHog를 떠난 후에도 **10년** 동안 베스팅된 옵션을 행사할 수 있다[^3]. 대부분의 회사가 90일 이내로 제한하는 것에 비해 크게 유리하다.

### 이중 트리거 가속

회사 인수로 인해 해고되거나 강제 퇴사해야 할 경우, 그 시점에 **모든 옵션이 즉시 부여(가속 베스팅)**된다[^4].

### 영국 세금 혜택 제도

영국 거주 구성원은 [EMI 제도](https://www.gov.uk/tax-employee-share-schemes/enterprise-management-incentives-emis) 또는 [CSOP 제도](https://www.gov.uk/tax-employee-share-schemes/company-share-option-plan) 중 적격한 방식으로 옵션을 부여받을 수 있다[^5].

## 부여 절차 및 일정

옵션 승인에는 이사회 결의와 기업가치 평가(valuation)가 필요하므로 시간이 걸릴 수 있다[^6]. 그러나 **베스팅은 항상 실제 입사일부터 소급 적용**된다 — 옵션 계약서를 받는 날이 아니다[^7].

특정 행사 가격(strike price)은 제3자 평가기관이 결정하므로 채용 시 확정값을 약속하기 어렵다[^8]. 옵션 수량은 확정할 수 있다.

펀딩 라운드 진행 중에는 새 옵션 발행이 지연될 수 있다[^9].

## 연간 리프레시(Equity Refreshes)

```mermaid
graph LR
    A["매년 성과 평가"] --> B["리프레시 규모 결정\n18%~25%"]
    B --> C["급여 검토 주기에 맞춰 통보"]
    C --> D["이사회 분기별 승인"]
    D --> E["베스팅 기념일부터 소급 시작"]
```

모든 구성원은 매년 주식 리프레시를 받을 자격이 있다[^10].

| 항목 | 내용 |
|------|------|
| 리프레시 규모 | 해당 역할 신규 부여 기준의 **18%~25%** |
| 비율 결정 기준 | 개인 성과 (연도별 변동) |
| 승인 주체 | 이사회 (분기별 승인) |
| 베스팅 시작 | 실제 기념일에 소급 적용 |
| 클리프 | 12개월 |

리프레시 그랜트는 원래 부여와 동일한 조건을 따르되, 가치 평가 변동으로 행사 가격이 다를 수 있다[^11]. 이사회 승인 시 Carta에서 안내 이메일이 발송된다[^12].

## 유동성(Liquidity)

PostHog는 구성원이 옵션을 현금화할 수 있는 세컨더리 거래 기회를 지원한다[^13].
