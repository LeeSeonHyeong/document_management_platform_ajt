# corpus-ajt — 시연용 AJT 사내 지식 코퍼스

발표 시연에 쓰는 가상 회사 **AJT** 의 원본문서와 위키 본문이다. 실제 데이터는
로컬 `ajt_demo` 스키마와 `backend/build/ajt-demo-documents/` 에 있는데, 그 경로가
`backend/.gitignore` 의 `build/` 에 걸려 버전 관리 밖이라 **내용만 여기에 남긴다.**

## 왜 두 곳에 두나

| | 어디 | 무엇을 위해 |
| --- | --- | --- |
| 복원용 | `../../../../backups/ajt-demo-*.tar.gz` | DB 행·해시·바이너리 원본까지 통째로 되살린다 |
| 열람·재사용용 | 여기 | 사람이 읽고 리뷰하고 2단계에서 다시 쓴다 |

tarball 은 복원은 되지만 diff 도 리뷰도 안 된다. 이 디렉터리는 그 반대다 —
**여기 있는 것만으로는 시연 환경을 되살리지 못한다.** 백업은
`ai/tools/demo-data/backup.sh` 로 따로 만든다.

## 구성

```
sources/<스코프>/           원본문서 (마크다운·텍스트)
parsed-from-binary/<스코프>/ docx·pdf 원본의 파싱본 — 원본 바이너리는 tarball 에만 있다
wikis/<스코프>/              위키 본문 (파일명은 해시가 아니라 제목이다)
```

스코프는 `ALL`(전사)·`D1`(개발부)·`D3`(디자인부)·`D4`(인사부).

## 출처

| 출처 | 문서 |
| --- | --- |
| `corpus-ko-wiki` (S15P11B106-177) | 취업규칙·인사위원회 회의록·개정공문·출장비 FAQ·팀리더 회의록·정보보안 |
| PostHog 핸드북 영문을 한국어로 옮긴 것 | 부업·보상·소통·교육·온보딩·퇴사·경력개발 |
| 시연용으로 새로 쓴 것 | 코딩 컨벤션·배포 파이프라인·디자인 시스템·브랜드 규정 |
| 관리자 채팅에서 생성된 것 | 관리자지시-* |

회사명은 **AJT** 로 통일했다. `PostHog`·`(주)아지트` 표기는 남아 있지 않다.

## 주의

- **계정·비밀번호 해시 같은 개인정보는 여기 없다.** DB 에만 있고 tarball 로만 나간다
- 위키 본문의 파일명은 읽기 좋게 제목으로 바꿨다. 실제 저장 경로는 `pages/<키>.md` 다
- 여기 파일을 고쳐도 시연 데이터에는 반영되지 않는다. 반대 방향(시연 데이터 → 여기)으로만 복사한다
