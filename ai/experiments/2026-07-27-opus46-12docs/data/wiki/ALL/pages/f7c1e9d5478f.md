PostHog는 새로운 협업 소프트웨어 도입에 신중하다[^1]. 협업 도구 하나가 추가되면 할 일·댓글·커뮤니케이션이 존재하는 장소가 하나 더 생기고, 이는 불균형적으로 큰 복잡성을 만든다[^2]. 개인 도구는 자유롭게 선택하되, 좋은 도구가 있으면 공유를 권장한다[^3].

## 도구 접근 권한 요청 (Zluri)

팀/회사 도구 접근은 Slack에서 Zluri 앱을 통해 요청한다[^4]

```mermaid
graph LR
    A["Slack에서 /accessrequest 입력"] --> B["팝업에서 앱 검색"]
    B --> C["라이선스 유형 기재"]
    C --> D["관리자 승인"]
    D --> E["이메일 초대 또는 SSO 로그인"]
```

목록에 없는 도구는 #team-people-and-ops에 문의한다[^5].

## 주요 도구

| 도구 | 용도 | 비고 |
|------|------|------|
| Loom | 화면 녹화 | 기본 Creator Lite (월 25건, 5분), 필요 시 Zluri에서 Creator 요청[^6] |
| Zoom | 화상 회의 | Google Meet 기본, Zoom은 무료(40분). 긴 미팅 필요 시 Zluri 요청[^7] |
| Superhuman | 이메일 | 팀 플랜 운영[^8] |
| Granola | AI 회의록 | AI 노트테이커 사용 가능하나 서브프로세서가 경쟁사 분석도구를 쓰지 않는지 확인[^9] |

## IDE

Visual Studio, VIM, PyCharm이 가장 많이 쓰인다[^10]. 최고급 IDE 제품군은 $700까지 갈 수 있으나 대부분의 엔지니어에게 가성비가 좋지 않다[^11].

## AI 코딩 도구

Cursor, Claude Code 등 AI 코딩 도구 사용을 권장한다[^12]. 다만 사용량 기반 과금은 빠르게 늘어날 수 있다[^12].

| 항목 | 기준 |
|------|------|
| 일반 월간 지출 | 최대 구독 1건 수준 (~$200/월)[^13] |
| 그 이상이면 | 설정 오류·비효율 워크플로우일 가능성 — 동료와 비교하고 #team-people-and-ops에 문의[^13] |

팀 Claude Code 계정이 있으며 Slack에서 Zluri로 추가 요청할 수 있다[^14].

## 신규 구독/엔터프라이즈 도구

새 도구나 엔터프라이즈 구독을 도입하면 Janani를 Billing Admin으로 추가해 결제를 관리하게 한다[^15]. 결제용 이메일이 필요하면 finance@posthog.com을 사용한다[^16].

## GitHub 업무 방식

PostHog는 비엔지니어링 업무 관리까지 GitHub를 쓴다[^21]. 비기술 직군이라면 초기에 적응이 필요할 수 있다[^22].

| 저장소 | 용도 |
|--------|------|
| PostHog (posthog) | 메인 앱[^23] |
| PostHog.com (posthog.com) | 웹사이트[^24] |
| Product Internal | 보안·고객별 이슈 (비공개)[^25] |
| Company Internal | 내부 프로세스·채용 계획 (비공개)[^26] |

GitHub Projects로 이슈 상태를 추적한다[^27]. 이슈 생성 시 프로젝트에 할당하면 소규모 팀이 여러 저장소에 걸친 작업을 한 곳에서 볼 수 있다[^28]. 대부분의 팀이 2주 스프린트를 운영한다[^29].
